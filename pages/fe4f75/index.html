mysql的安装

# 安装 MySQL 8.0（推荐）

# 1. 检查系统版本

cat /etc/centos-release
1

输出应该类似：

CentOS Linux release 7.9.2009 (Core)
1

# 2. 删除系统自带 MariaDB（如果安装过）

查看：

rpm -qa | grep mariadb
1

删除：

yum remove mariadb*
1

# 3. 下载 MySQL 官方 Yum 仓库

wget https://repo.mysql.com/mysql80-community-release-el7-11.noarch.rpm
1

如果没有 wget：

yum install -y wget
1

安装仓库：

rpm -ivh mysql80-community-release-el7-11.noarch.rpm
1

或者

yum localinstall mysql80-community-release-el7-11.noarch.rpm
1

这是 Oracle 官方推荐的安装方式。

# 4. 安装 MySQL

yum install -y mysql-community-server
1

查看安装版本：

mysqld --version
1

例如：

mysqld  Ver 8.0.xx
1

# 5. 启动 MySQL

systemctl start mysqld
1

设置开机启动：

systemctl enable mysqld
1

查看状态：

systemctl status mysqld
1

# 6. 获取初始密码

首次安装，MySQL 会生成随机密码。

grep 'temporary password' /var/log/mysqld.log
1

例如：

A temporary password is generated for root@localhost:
abcD!1234....
1
2

mysql -uroot -p
1

# 允许远程登录

# 第一步：登录 MySQL

先在服务器本地登录：

mysql -uroot -p
1

输入 root 密码。

# 第二步：查看 root 用户

执行：

SELECT user, host FROM mysql.user;
1

例如可能看到：

+------+-----------+
| user | host      |
+------+-----------+
| root | localhost |
| mysql.sys | localhost |
+------+-----------+
1
2
3
4
5
6

如果只有

root@localhost
1

说明只能本机连接。

# 第三步：创建远程 root 用户（推荐）

MySQL 8.0 推荐这种方式。

执行：

CREATE USER 'root'@'%' IDENTIFIED BY '你的Root密码';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;
1
2
3

然后再次查看：

SELECT user,host FROM mysql.user;
1

应该变成：

root    localhost
root    %
1
2

这里：

  • localhost：本地登录
  • %：任何IP都可以登录

# 第四步：修改 bind-address（如果有）

查看配置：

grep bind-address /etc/my.cnf
1

或者

grep bind-address /etc/my.cnf.d/*.cnf
1

如果有：

bind-address=127.0.0.1
1

改成：

bind-address=0.0.0.0
1

或者直接注释：

# bind-address=127.0.0.1
1

保存。

# 第五步：重启 MySQL

systemctl restart mysqld
1

查看监听：

ss -lntp | grep 3306
1

应该看到：

0.0.0.0:3306
1

而不是

127.0.0.1:3306
1

# 第六步：开放防火墙

CentOS 7：

firewall-cmd --permanent --add-port=3306/tcp
firewall-cmd --reload
1
2

查看：

firewall-cmd --list-ports
1

应该有：

3306/tcp
1

# 第七步：SELinux（如果开启）

查看：

getenforce
1

如果返回：

Enforcing
1

执行：

setsebool -P mysql_connect_any 1
1

或者测试阶段先关闭：

setenforce 0
1

# 第八步：使用 Navicat 测试

填写：

Host：10.13.0.171
Port：3306
User：root
Password：你的密码
