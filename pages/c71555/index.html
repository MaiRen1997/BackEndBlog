centOS7上定时备份

# 创建备份脚本

# 创建备份目录

mkdir -p /data/mysql_backup
1

# 编写脚本

vim /data/mysql_backup/mysql_backup.sh
1
#!/bin/bash

# --- 数据库连接配置 ---
DB_USER="root"                # 数据库用户名
DB_PASS="your_password"       # 数据库密码（生产环境建议使用配置文件，避免明文密码）
DB_HOST="localhost"           # 数据库主机

# --- 备份配置 ---
BACKUP_DIR="/data/mysql_backup" # 备份文件存放目录
DATE=$(date +"%Y%m%d_%H%M%S")   # 生成带时间戳的文件名
KEEP_DAYS=7                     # 备份保留天数

# 创建备份目录（如果不存在）
mkdir -p $BACKUP_DIR

# --- 执行备份 ---
# 备份所有数据库，并压缩为 .sql.gz 文件
mysqldump -h$DB_HOST -u$DB_USER -p$DB_PASS --all-databases --single-transaction --quick --lock-tables=false | gzip > $BACKUP_DIR/all_databases_$DATE.sql.gz

# --- 清理过期备份 ---
# 查找并删除 $KEEP_DAYS 天前的备份文件
find $BACKUP_DIR -type f -name "*.sql.gz" -mtime +$KEEP_DAYS -exec rm {} \;

echo "Backup completed: $BACKUP_DIR/all_databases_$DATE.sql.gz"

关键参数说明：

  • --all-databases：备份所有数据库。你也可以用 --databases db1 db2 指定特定库，或直接写库名备份单个库。
  • --single-transaction：对于 InnoDB 引擎，可以在不锁表的情况下获得一致性快照，生产环境强烈建议保留此参数。

# 添加定时任务

  1. 新增一个文件夹，用于存储定时备份的日志，并给文件夹赋值权限

    mkdir /data/mysql_backup_log
chmod 755 /data/mysql_backup_log
    1
    2

  2. 在文件末尾增加一行

    0 0 * * * /data/mysql_backup/mysql_backup.sh >> /data/mysql_backup_log/mysql_backup.log 2>&1
    1

  3. 时间格式

    分 时 日 月 周
    1

  4. 对照参考表

    时间 分 时 crontab 写法
    凌晨 0 点（原设置） 0 0 0 0 * * *
    凌晨 4 点 0 4 0 4 * * *
    下午 14 点 0 14 0 14 * * *
    晚上 23 点 30 分 30 23 30 23 * * *

  5. 手动验证脚本正确性

    #在命令行中直接运行
/data/mysql_backup/mysql_backup.sh

    3
