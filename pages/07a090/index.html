前端docker命令编写

# 1.完整命令

# 构建阶段
FROM node:18-slim AS builder
WORKDIR /app

# 复制源代码
COPY . .

# 设置npm镜像源
RUN npm config set registry https://registry.npmmirror.com

# 安装依赖
RUN npm install

# 执行docker构建命令
RUN npm run build:docker

# 运行阶段
FROM nginx:latest
WORKDIR /usr/share/nginx/html

# 复制构建产物
COPY --from=builder /app/dist .

# 暴露端口
EXPOSE 80

# 启动nginx
CMD ["nginx", "-g", "daemon off;"]

# 2.命令解析

# 1.拉取镜像

# 构建阶段
FROM node:18-slim AS builder
1
2
  1. From 用来拉取镜像，后面跟镜像的名称
  2. 如果镜像需要指定node版本，可以使用FROM node:18.17.0
    1. FROM node:18.17.0 # 精确版本
    2. FROM node:18.17 # 次版本号
    3. FROM node:18 # 大版本（会自动更新到最新的18.x）
    4. FROM node:18-slim # 轻量版 + 大版本
    5. FROM node:18.17.0-slim # 轻量版 + 精确版本
  3. AS 是给这个阶段取个别名
  4. 如果需要从阿里云拉取镜像，可以使用FROM registry.cn-hangzhou.aliyuncs.com/fs-devops/node:16

# 2.设置工作目录

WORKDIR 是 Dockerfile 中的一个指令，用于设置容器内的工作目录。它类似于在容器中执行 cd 命令

这个路径是容器内的路径

如果没有，会重新创建一个并切换到这个目录

后续的RUN、CMD、COPY等命令，都是在这个目录下完成的

WORKDIR /app
1

常用目录

目录名 用途 常见于
/app 应用程序代码 通用，最常用 ✅
/usr/src/app 应用源码 Debian/Ubuntu 系列
/home/node/app Node.js 应用 Node 官方镜像推荐
/var/www/html Web 应用 PHP/Apache 镜像
/code 开发项目 GitLab CI 等

# 3.COPY复制源码

# 3.1.从宿主机复制到容器

COPY . .
1
  • 第一个 .：宿主机的当前目录（即构建上下文）
    • 这个是基于DockerFile所在的目录为根目录进行的
  • 第二个 .：容器内的当前工作目录（由 WORKDIR 指定）

完整解读：将宿主机当前目录下的所有文件和文件夹，复制到容器内 /app 目录下

# 3.2从上个阶段复制到当前阶段

COPY --from=builder /app/dist .
1

--from=builder 是 Docker 多阶段构建中的跨阶段复制语法

  1. --from= 是指定多阶段
  2. builder是给阶段取的别名
  3. 此处的COPY就是从上个阶段，复制到当前阶段的根目录，而不再是宿主机到容器了
  4. 阶段之间的划分，是以FROM为依据的

# 使用FROM拉取nginx镜像

# 使用WORKDIR切换路径

  1. 要通过官网https://hub.docker.com/查看nginx相关的文档，查看html是放在哪个位置的

# 使用EXPOSE暴露接口

1

# 使用CMD运行命令

CMD ["nginx", "-g", "daemon off;"]
1

daemon off：Nginx 配置指令：关闭守护进程模式（前台运行）

Docker 容器的生命周期依赖于前台进程：

  • 如果容器的主进程（PID 1）退出，容器就会停止
  • Nginx 默认以守护进程（daemon）方式运行，会立即退出
  • 因此需要让 Nginx 在前台运行，保持容器存活
