## 同步数据库代码实现

### 创建数据库名、架构模式、表名

1. 数据库名：SOURCE_DATABASE = 'AIS20220419132724'

   1. **作用**：
      1. 指定要连接的**数据库名称**
      2. 在 `_fetch_source_data` 方法中作为参数传递给 `SqlServerConnector.fetch_table_rows`
      3. 告诉连接器从哪个数据库读取数据

2. 架构模式：SOURCE_SCHEMA = 'dbo'

   1. **作用**：指定数据库的**架构/模式（Schema）**
      1. SQL Server中，Schema是数据库对象的容器（如表、视图等）
      2. `dbo`（Database Owner）是SQL Server的默认架构
      3. 用于定位表所在的完整路径

3. 表名：SOURCE_TABLE = 'Table_Cbuse_zh'

   1. **作用**：
      1. 指定要读取的**源表名称**
      2. 这是实际存储数据的数据表名

4. 字段名映射关系：FIELD_ALIASES

   1. ### 作用：

      - **键（Key）**：目标表 `CbusSyncTable` 中的字段名
      - **值（Value）**：源表中可能使用的各种字段名变体（列表）
      - **目的**：适配源表字段名的多样性，提高健壮性

5. 源表查询列列表：SOURCE_COLUMNS 

   1. ### 作用：

      - **指定要查询的源表字段列表**
      - 告诉 `SqlServerConnector.fetch_table_rows` 只查询这些列
      - 对应源表 `Table_Cbuse_zh` 的实际列名

### _normalize_key(规范字段名称)

**作用**：规范化字段名称，用于字段匹配

**具体功能**：

- 去除首尾空格

- 转为小写

- 只保留字母数字和中文字符（过滤掉特殊符号如 `_`、`.` 等）

- ```python
  _normalize_key("contract_no")  # → "contractno"
  _normalize_key("合同号")       # → "合同号"
  _normalize_key("fHTH")         # → "fhth"
  ```

### _normalize_str_value(规范值)

1. **作用**：规范化字符串值

2. **具体功能**：

   - 处理 `None` 值，返回 `None`

   - 转为字符串并去除首尾空格

   - 处理编码问题（忽略无法编码的字符）

   - 空字符串返回 `None`

3. **使用场景**：处理除日期外的所有文本字段

### _normalize_datetime_value(日期格式转为datetime)

1. **作用**：将各种格式的日期数据统一转为 `datetime` 对象

2. **具体功能**：

   - 处理 `None` 值

   - 处理已经是 `datetime` 或 `date` 类型的值

   - 支持 pandas 的 Timestamp 类型

   - 尝试多种常见日期格式（`%Y-%m-%d`、`%Y/%m/%d`、ISO格式等）

3. **支持格式示例**：

   ```python
   "2026-08-13"           → datetime(2026, 8, 13)
   "2026/08/13 14:30:00"  → datetime(2026, 8, 13, 14, 30)
   "2026-08-13T14:30:00"  → datetime(2026, 8, 13, 14, 30)
   ```

4. **使用场景**：专门处理 `product_date` 字段

### _pick_value(从源数据按列取值)

1. **作用**：从源数据行中按别名列表查找匹配的字段值

2. **具体功能**：

   1. 将源数据行的所有字段名规范化

   1. 遍历别名列表，逐个尝试匹配

   1. 找到第一个匹配的字段就返回值

3. **示例**：

```python
row = {'fHTH': 'C2024001', 'fa': '10层'}
# 查找 'floor_params' 的别名 ['fa','floor_params','floorParams','层']
_pick_value(row, ['fa','floor_params','floorParams','层'])  # → '10层'
```

### _transform_row(单行源数据转换为目标格式)

1. 作用：将单行源数据转换为目标格式

2. 具体功能：
   1. 提取并验证合同号（必填字段）

   2. 如果合同号为空，跳过该行
   3. 遍历 FIELD_ALIASES，将源字段映射到目标字段

   4. 对日期字段特殊处理

   5. 返回转换后的字典

### _fetch_source_data(从SQL Server源表异步获取原始数据)

1. **作用**：从SQL Server源表异步获取原始数据

2. **具体功能**：

   - 使用 `asyncio.to_thread` 将同步的数据库操作转为异步

   - 调用 `SqlServerConnector.fetch_table_rows` 执行查询

   - 传入数据库名、架构名、表名、列列表、行数限制

   - 返回源数据列表

### sync_to_cbus_table

1. **作用**：**核心方法**，执行完整的同步流程
2. **具体功能**：
   1. **获取源数据**：调用 `_fetch_source_data`
   2. **转换数据**：遍历源数据，调用 `_transform_row` 转换每条记录
   3. **去重处理**：查询目标表中已存在的合同号
   4. **筛选新增**：只插入不存在的合同号
   5. **批量插入**：通过 `CbussyncDao.add_cbusSync_dao` 逐条插入
   6. **事务管理**：成功则提交，失败则回滚
   7. **日志记录**：记录同步结果和统计信息
3. **返回值**：实际新增的记录条数



```python
import asyncio
from datetime import date, datetime
from typing import Any

import pandas as pd
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from config.sqlserver import SqlServerConnector
from module_certification.dao.cbusSync_dao import CbussyncDao
from module_certification.entity.do.cbusSync_do import CbusSyncTable
from module_certification.entity.vo.cbusSync_vo import CbussyncModel
from utils.common_util import CamelCaseUtil
from utils.log_util import logger


class CbusSyncSqlServerSyncService:
    """
    SQL Server -> cbus_sync_table 同步服务
    """

    SOURCE_DATABASE = 'AIS20220419132724'
    SOURCE_SCHEMA = 'dbo'
    SOURCE_TABLE = 'Table_Cbuse_zh'

    FIELD_ALIASES: dict[str, list[str]] = {
        'contract_no': ['fHTH','contract_no', 'contractNo', 'contractno', '合同号'],
        'floor_params': ['fa','floor_params', 'floorParams', '层'],
        'door_params': ['fb','door_params', 'doorParams', '门'],
        'station_params': ['fc','station_params', 'stationParams', '站'],
        'load_capacity': ['fd','load_capacity', 'loadCapacity', '载重'],
        'rated_speed': ['fe','rated_speed', 'ratedSpeed', '额定速度'],
        'control_style': ['ff','control_style', 'controlStyle', '控制方式'],
        'lift_control_style': ['fg','lift_control_style', 'liftControlStyle', '梯控方式'],
        'open_door_style': ['fh','open_door_style', 'openDoorStyle', '开门方式'],
        'increase_height': ['fi','increase_height', 'increaseHeight', '提升高度'],
        'suspension_ratio': ['fj','suspension_ratio', 'suspensionRatio', '悬挂比'],
        'elevator_width': ['fk','elevator_width', 'elevatorWidth', '轿厢净宽'],
        'elevator_deep': ['fl','elevator_deep', 'elevatorDeep', '轿厢净深'],
        'elevator_height': ['fm','elevator_height', 'elevatorHeight', '轿厢净高'],
        'elevator_size': ['fn','elevator_size', 'elevatorSize', '轿厢尺寸'],
        'elevator_area': ['fo','elevator_area', 'elevatorArea', '轿厢有效面积'],
        'elevator_weight': ['fp','elevator_weight', 'elevatorWeight', '轿厢自重'],
        'floor_station_door': ['fq','floor_station_door', 'floorStationDoor', '层/站/门'],
        'extra_weight': ['fr','extra_weight', 'extraWeight', '额外装潢重量'],
        'standard_load': ['fs','standard_load', 'standardLoad', '轿厢设计自重及范围'],
        'product_date': ['fccdate','product_date', 'productDate', '出厂日期', '出场日期'],
        'serial_no': ['fcpbhdm','serial_no', 'serialNo', '设备编号代码'],
    }
    SOURCE_COLUMNS = ['fHTH', 'fa', 'fb', 'fc', 'fd', 'fe', 'ff', 'fg', 'fh', 'fi', 'fj', 'fk', 'fl', 'fm', 'fn', 'fo', 'fp', 'fq', 'fr', 'fs', 'fccdate', 'fcpbhdm']

    @classmethod
    def _normalize_key(cls, key: str) -> str:
        return ''.join(ch for ch in str(key).strip().lower() if ch.isalnum() or '\u4e00' <= ch <= '\u9fff')

    @classmethod
    def _normalize_str_value(cls, value: Any) -> str | None:
        if value is None:
            return None
        value_str = str(value).strip()
        value_str = value_str.encode('utf-8', errors='ignore').decode('utf-8', errors='ignore')
        return value_str if value_str else None

    @classmethod
    def _normalize_datetime_value(cls, value: Any) -> datetime | None:
        if value is None:
            return None
        if isinstance(value, datetime):
            return value
        if isinstance(value, date):
            return datetime.combine(value, datetime.min.time())
        if hasattr(value, 'to_pydatetime'):
            try:
                return value.to_pydatetime()
            except Exception:
                pass

        value_str = str(value).strip()
        if not value_str:
            return None

        try:
            import pandas as pd
            parsed = pd.to_datetime(value_str, errors='raise')
            if hasattr(parsed, 'to_pydatetime'):
                return parsed.to_pydatetime()
            return parsed
        except Exception:
            pass

        for fmt in (
            '%Y-%m-%d %H:%M:%S.%f',
            '%Y-%m-%d %H:%M:%S',
            '%Y-%m-%d',
            '%Y/%m/%d %H:%M:%S',
            '%Y/%m/%d',
            '%Y-%m-%dT%H:%M:%S.%f',
            '%Y-%m-%dT%H:%M:%S',
        ):
            try:
                return datetime.strptime(value_str, fmt)
            except ValueError:
                pass

        try:
            return datetime.fromisoformat(value_str.replace('Z', '+00:00'))
        except ValueError:
            return None

    @classmethod
    def _pick_value(cls, row: dict[str, Any], aliases: list[str]) -> Any:
        normalized_index = {cls._normalize_key(k): v for k, v in row.items()}
        for alias in aliases:
            alias_key = cls._normalize_key(alias)
            if alias_key in normalized_index:
                return normalized_index[alias_key]
        return None

    @classmethod
    def _transform_row(cls, row: dict[str, Any]) -> dict[str, Any] | None:
        contract_no = cls._normalize_str_value(cls._pick_value(row, cls.FIELD_ALIASES['contract_no']))
        if not contract_no:
            return None
        item: dict[str, Any] = {'contract_no': contract_no}
        for field_name, aliases in cls.FIELD_ALIASES.items():
            if field_name == 'contract_no':
                continue
            raw_value = cls._pick_value(row, aliases)
            if field_name == 'product_date':
                item[field_name] = cls._normalize_datetime_value(raw_value)
            else:
                item[field_name] = cls._normalize_str_value(raw_value)
        return item

    @classmethod
    async def _fetch_source_data(cls, limit: int | None = None) -> list[dict[str, Any]]:
        return await asyncio.to_thread(
            SqlServerConnector.fetch_table_rows,
            cls.SOURCE_DATABASE,
            cls.SOURCE_SCHEMA,
            cls.SOURCE_TABLE,
            cls.SOURCE_COLUMNS,
            limit,
            True,
        )

    @classmethod
    async def sync_to_cbus_table(cls, query_db: AsyncSession, limit: int | None = None) -> int:
        """
        同步SQL Server数据到cbus_sync_table，合同号重复则跳过

        :param query_db: orm对象
        :param limit: 限制同步条数
        :return: 新增数量
        """
        source_rows = await cls._fetch_source_data(limit=limit)
        if not source_rows:
            logger.info('ℹ️ SQL Server源表暂无可同步数据')
            return 0

        transformed_rows: dict[str, dict[str, Any]] = {}
        for row in source_rows:
            item = cls._transform_row(row)
            if item:
                transformed_rows[item['contract_no']] = item

        if not transformed_rows:
            logger.warning('⚠️ SQL Server源表数据缺少合同号，已全部跳过')
            return 0

        contract_no_list = list(transformed_rows.keys())
        query_result = await query_db.execute(
            select(CbusSyncTable.contract_no).where(CbusSyncTable.contract_no.in_(contract_no_list))
        )
        existing_contract_no_set = set(query_result.scalars().all())

        insert_count = 0
        try:
            for contract_no, row_data in transformed_rows.items():
                if contract_no in existing_contract_no_set:
                    continue
                cbus_sync_vo = CbussyncModel(**CamelCaseUtil.transform_result(row_data))
                await CbussyncDao.add_cbusSync_dao(query_db, cbus_sync_vo)
                insert_count += 1
            await query_db.commit()
        except Exception:
            await query_db.rollback()
            raise

        logger.info(f'✅ SQL Server同步完成，新增{insert_count}条，源数据{len(source_rows)}条')
        return insert_count

```
