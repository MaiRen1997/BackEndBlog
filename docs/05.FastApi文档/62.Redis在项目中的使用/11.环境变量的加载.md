## 在config/env.py中调用

### parse_cli_args的调用

#### 作用

1. parse_cli_args()的作用是判断当前程序是通过什么方式启动的，确定要使用哪个运行环境，然后加载对应的 `.env` 配置文件

   1. ```
      --env prod
          ↓
      APP_ENV=prod
          ↓
      加载 .env.prod
          ↓
      数据库、Redis、JWT 等配置读取生产环境的值
      ```

#### 调用时机

1. 由于`env.py`文件最后有`get_config = GetConfig()`，

2. 当引入env.py这个文件之后，就会执行`get_config = GetConfig()`这个实例化，

3. 由于在定义`GetConfig`类时，定义了self方法，会执行`parse_cli_args`,从而确定是属于哪个环境

4. 所以只要导入这个文件，就会导入环境变量

5. ```
   导入 config.env
       ↓
   创建 GetConfig()
       ↓
   执行 parse_cli_args()
       ↓
   确定 APP_ENV
       ↓
   加载 .env.dev 或 .env.prod
       ↓
   创建 AppConfig、DataBaseConfig、RedisConfig 等对象
   ```

### parse_cli_args的解析

#### 启动方式判断

1. 这个方法把启动方式分成了三类：

   1. ```
      if 是 Alembic:
          ...
      elif 是 Uvicorn:
          ...
      else:
          ...
      ```


#### 启动方式详解

1. `python main.py --env prod`

   1. ```
      sys.argv == [
          "main.py",
          "--env",
          "prod",
      ]
      ```

2. `Uvicorn 启动`

   1. ```python
      uvicorn app:app --host 0.0.0.0 --port 9099 --reload
      
      sys.argv == [
          ".../uvicorn",
          "app:app",
          "--host",
          "0.0.0.0",
          "--port",
          "9099",
          "--reload",
      ]
      ```

3. `Alembic 启动`

   1. 方式一

      1. ```
         alembic upgrade head
         
         sys.argv == [
             ".../alembic",
             "upgrade",
             "head",
         ]
         ```

   2. 方式二

      1. ```
         python -m alembic revision --autogenerate -m "add user"
         
         sys.argv == [
             ".../python",
             "-m",
             "alembic",
             "revision",
             "--autogenerate",
             "-m",
             "add user",
         ]
         ```

#### Alembic 启动--读取ini文件

```
ini_config = configparser.ConfigParser()
ini_config.read('alembic.ini', encoding='utf-8')
```

1. 第一段代码

   创建一个 `ConfigParser` 对象，用来解析 `.ini` 格式的配置文件。

   可以把 `ini_config` 理解为一个“配置文件读取器”。

2. 第二段代码：读取文件

   ```
   ini_config.read('alembic.ini', encoding='utf-8')
   ```

   读取当前工作目录下的 `alembic.ini`

   按照 UTF-8 编码解析文件内容

   将读取结果保存到 `ini_config` 对象中

###  argparse.ArgumentParser的使用

```python
 # 使用argparse定义命令行参数
 parser = argparse.ArgumentParser(description='命令行参数')
 parser.add_argument('--env', type=str, default='', help='运行环境')
 # 解析命令行参数
 args, unknown_args = parser.parse_known_args()
 # 设置环境变量，如果未设置命令行参数，默认APP_ENV为dev
 os.environ['APP_ENV'] = args.env if args.env else 'dev'
```

1. `parser = argparse.ArgumentParser(...)`

   1. 相当于创建一个工具，专门负责解析当前 Python 进程收到的命令行参数。

2. `parser.add_argument('--env', ...)`

   1. 这表示当前解析器只声明了一个自定义可选参数`env`

   2. 合法的运行命令：python main.py --env prod

   3. 如果需要添加多个参数，则需要写多行的`add_argument`

      1. ```python
         parser.add_argument('--env', type=str, default='')
         parser.add_argument('--port', type=int, default=9099)
         parser.add_argument('--debug', action='store_true')
         
         args, unknown_args = parser.parse_known_args()
         ```

3. `args, unknown_args = parser.parse_known_args()`

   1. 它会把参数分成两类：

      - 已经通过 `add_argument()` 声明的参数；
      - 当前解析器不认识的其他参数。

   2. 如命令`python main.py --env prod --port 9099 --reload`

      1. 会解析成两种

         1. ```
            args.env == 'prod'
            
            unknown_args == [
                '--port',
                '9099',
                '--reload',
            ]
            ```



## 完整代码

```python
from pydantic_settings import BaseSettings

class RedisSettings(BaseSettings):
    """
    Redis配置
    """

    redis_host: str = '127.0.0.1'
    redis_port: int = 6379
    redis_username: str = ''
    redis_password: str = ''
    redis_database: int = 2
    
    
#定义获取配置方法
class GetConfig:
    """
    获取配置
    """
    
    def __init__(self) -> None:
        self.parse_cli_args()
        
        
    @staticmethod
    def parse_cli_args() -> None:
        """
        解析命令行参数
        """
        # 检查是否在alembic环境中运行，如果是则跳过参数解析
        if 'alembic' in sys.argv[0] or any('alembic' in arg for arg in sys.argv):
            ini_config = configparser.ConfigParser()
            ini_config.read('alembic.ini', encoding='utf-8')
            if 'settings' in ini_config:
                # 获取env选项
                env_value = ini_config['settings'].get('env')
                os.environ['APP_ENV'] = env_value if env_value else 'dev'
        elif 'uvicorn' in sys.argv[0]:
            # 使用uvicorn启动时，命令行参数需要按照uvicorn的文档进行配置，无法自定义参数
            pass
        else:
            # 使用argparse定义命令行参数
            parser = argparse.ArgumentParser(description='命令行参数')
            parser.add_argument('--env', type=str, default='', help='运行环境')
            # 解析命令行参数
            args, _ = parser.parse_known_args()
            # 设置环境变量，如果未设置命令行参数，默认APP_ENV为dev
            os.environ['APP_ENV'] = args.env if args.env else 'dev'
        # 读取运行环境
        run_env = os.environ.get('APP_ENV', '')
        # 运行环境未指定时默认加载.env.dev
        env_file = '.env.dev'
        # 运行环境不为空时按命令行参数加载对应.env文件
        if run_env != '':
            env_file = f'.env.{run_env}'
        # 加载配置
        load_dotenv(env_file)
    
    
    def get_redis_config(self) -> RedisSettings:
        """
        获取Redis配置
        """
        # 实例化Redis配置模型
        return RedisSettings()
    

```
