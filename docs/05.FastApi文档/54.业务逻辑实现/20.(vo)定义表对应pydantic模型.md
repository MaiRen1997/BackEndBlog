## 普通定义

1. `时间`用`datetime`

2. `数字`用`int`

3. `字符串`用`str`

4. `布尔`用`bool`

5. 多类型

   1. 也可以在后面跟上其他类型

   2. ```python
      success: bool | None = Field(default=True, description='响应是否成功')
      ```

6. 完整代码

   1. ```python
      from datetime import datetime
      class ResponseBaseModel(BaseModel):
          """
          响应模型
          """
          code: int = Field(default=HttpStatusConstant.SUCCESS, description='响应码')
          msg: str = Field(default='操作成功', description='响应信息')
          success: bool = Field(default=True, description='响应是否成功')
          time: datetime = Field(default_factory=datetime.now, description='响应时间')
      ```


## 结合泛型定义

### 定义

```python
from typing import Any, Generic, TypeVar

class DataResponseModel(ResponseBaseModel, Generic[T]):
    """
    数据响应模型
    """

    data: T = Field(description='响应数据')
```

### 使用

```python
# 使用时指定具体类型
# 返回用户数据
response: DataResponseModel[User] = DataResponseModel(
    code=200,
    message="success",
    data=user_obj
)

# 返回列表数据
response: DataResponseModel[List[User]] = DataResponseModel(
    code=200,
    message="success",
    data=[user1, user2]
)

# 返回字符串
response: DataResponseModel[str] = DataResponseModel(
    code=200,
    message="success",
    data="hello"
)
```

## model_config中ConfigDict的使用

### 概述

1. `ConfigDict` 是 Pydantic v2 的配置类，用于控制模型的行为。在这里：

   1. ```python
      from datetime import datetime
      from pydantic import BaseModel, ConfigDict, Field
      from pydantic.alias_generators import to_camel
      from pydantic_validation_decorator import NotBlank
      
      class Ard_infoModel(BaseModel):
          """
          ard信息表对应pydantic模型
          """
          model_config = ConfigDict(alias_generator=to_camel, from_attributes=True, populate_by_name= True)
          contract_no: str | None = Field(default=None, description='合同号')
          update_time: datetime | None = Field(default=None, description='更新时间')
      ```

2. **各参数作用**：

   - `alias_generator=to_camel`：允许进行驼峰转换

   - **`from_attributes=True`**：允许从 ORM 对象（如 SQLAlchemy）或其他类实例创建模型

   - **`populate_by_name=True`**：既能用字段名也能用别名来初始化/访问数据


### alias_generator的使用

1. `to_camel` 是 Pydantic 提供的**驼峰命名转换器**，将 Python 的蛇形命名（snake_case）转换为驼峰命名（camelCase）：

2. **典型应用场景**：

   - Python 后端习惯用 `snake_case`

   - 前端 JavaScript 习惯用 `camelCase`

   - 自动转换，无需手动映射

3. ```python
   from pydantic.alias_generators import to_camel
   
   # 实际使用效果
   class UserModel(BaseModel):
       model_config = ConfigDict(alias_generator=to_camel)
       
       user_name: str      # Python中保持 snake_case
       user_age: int       # Python中保持 snake_case
       phone_number: str   # Python中保持 snake_case
   
   # JSON 序列化/反序列化时自动转换
   user = UserModel(user_name="张三", user_age=25, phone_number="13800138000")
   print(user.model_dump(by_alias=True))
   # 输出: {"userName": "张三", "userAge": 25, "phoneNumber": "13800138000"}
   ```

### from_attributes的作用

#### 没有 `from_attributes` 时（默认 False）：

```python
# 只能从字典创建
user_data = {"name": "张三", "age": 25}
user = UserModel(**user_data)  # ✅ 可以

# 从对象创建会报错
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

user_obj = User("张三", 25)
user = UserModel(user_obj)  # ❌ 报错：需要字典类型
```

#### 有 `from_attributes=True` 时：

```python
class UserModel(BaseModel):
    model_config = ConfigDict(from_attributes=True)
    name: str
    age: int

# 可以从 ORM 对象创建
class SQLAlchemyUser:
    def __init__(self, name, age):
        self.name = name
        self.age = age

db_user = SQLAlchemyUser("张三", 25)
user = UserModel.model_validate(db_user)  # ✅ 支持从属性读取
# 或者直接传入对象
user = UserModel(db_user)  # ✅ 也可以
```



#### 典型应用场景：

1. 可以直接将从数据库查询得到 ORM 对象，转换成Pydantic 模型（返回给前端）

2. 如下:将`UserModel`的`model_config`的`from_attributes=True`

3. ```python
   # SQLAlchemy ORM 对象
   from sqlalchemy import Column, String, Integer
   
   class UserDB(Base):
       __tablename__ = 'users'
       name = Column(String)
       age = Column(Integer)
   
   # 从数据库查询得到 ORM 对象
   db_user = session.query(UserDB).first()  # 返回 UserDB 实例
   
   # 直接转换为 Pydantic 模型（返回给前端）
   response_user = UserModel.model_validate(db_user)  # ✅ from_attributes=True 支持
   ```

### populate_by_name

**作用**：允许使用**字段名**或**别名**来初始化和访问数据。

#### 没有 `populate_by_name` 时（默认 False）：

```python
class UserModel(BaseModel):
    model_config = ConfigDict(alias_generator=to_camel)
    user_name: str  # 别名自动生成为 userName
    user_age: int   # 别名自动生成为 userAge

# ✅ 可以用别名创建
user = UserModel(userName="张三", userAge=25)

# ❌ 不能用原始字段名创建（会报错）
user = UserModel(user_name="张三", user_age=25)  
# 报错：Extra inputs are not permitted
```

#### 有 `populate_by_name=True` 时：

```python
class UserModel(BaseModel):
    # 允许使用原始字段名
    model_config = ConfigDict( alias_generator=to_camel, populate_by_name=True)
    user_name: str
    user_age: int

# ✅ 两种方式都可以
user1 = UserModel(userName="张三", userAge=25)  # 使用别名
user2 = UserModel(user_name="张三", user_age=25)  # 使用原始字段名

# ✅ 访问时两种方式都可以
print(user1.user_name)    # 原始字段名
print(user1.userName)     # 别名也可以访问
```

### 以上三者者配合使用的完整示例

1. 前端可以通过驼峰传入数值`alias_generator=to_camel`

2. 可以从数据库取值，直接放入到模型中`from_attributes=True`

3. 可以通过小驼峰、下划线两种方式访问变量`populate_by_name=True`

4. ```python
   from pydantic import BaseModel, ConfigDict
   from pydantic.alias_generators import to_camel
   
   # 1. 定义 ORM 模型（数据库）
   class UserDB:
       def __init__(self, user_name, user_age, user_email):
           self.user_name = user_name
           self.user_age = user_age
           self.user_email = user_email
   
   # 2. 定义 Pydantic 模型（API 响应）
   class UserResponse(BaseModel):
       model_config = ConfigDict(
           alias_generator=to_camel,      # 前端用 camelCase
           from_attributes=True,           # 可以从 ORM 对象转换
           populate_by_name=True           # 可以同时使用字段名和别名
       )
       user_name: str
       user_age: int
       user_email: str | None = None
   
   # 3. 实际使用场景
   # 从数据库获取数据
   db_user = UserDB("张三", 25, "zhangsan@example.com")
   
   # 转换为 API 响应模型（from_attributes 起作用）
   response = UserResponse.model_validate(db_user)
   
   # 序列化为 JSON 返回给前端（alias 起作用）
   json_response = response.model_dump(by_alias=True)
   print(json_response)
   # 输出: {"userName": "张三", "userAge": 25, "userEmail": "zhangsan@example.com"}
   
   # 同时，内部代码可以用原始字段名访问（populate_by_name 起作用）
   print(response.user_name)  # ✅ "张三"
   print(response.userName)   # ✅ 也可以访问 "张三"
   ```

## NotBlank的使用

### 定义

1. `@NotBlank` 是一个**自定义验证装饰器**（来自 `pydantic_validation_decorator` 库），用于验证字段不能为空或空白字符串：

2. ```python
   from datetime import datetime
   from pydantic import BaseModel, ConfigDict, Field
   from pydantic.alias_generators import to_camel
   from pydantic_validation_decorator import NotBlank
   
   class Ard_infoModel(BaseModel):
       """
       ard信息表对应pydantic模型
       """
       model_config = ConfigDict(alias_generator=to_camel, from_attributes=True, populate_by_name= True)
       contract_no: str | None = Field(default=None, description='合同号')
       update_time: datetime | None = Field(default=None, description='更新时间')
       
       @NotBlank(field_name='contract_no', message='合同编号不能为空')
       def get_contract_no(self) -> str | None:
           return self.contract_no
       @NotBlank(field_name='start_date', message='更新时间不能为空')
       def get_update_time(self) -> datetime | None:
           return self.start_date
   
       def validate_fields(self) -> None:
           self.get_contract_no()
           self.get_update_time()
   ```

### 使用

1. 如果 contract_no 为空，会抛出异常，抛出 ValidationError

2. ```python
   edit_user_model = UserModel(
                               contract_no=user_info.contract_no,
                               update_time=row['update_time']
                           )
   # 如果 contract_no 为空，会抛出异常
   edit_user_model.validate_fields() # ❌ 抛出 ValidationError
   ```

## 动态响应模型

### 固定的动态，在data中变化

1. 如果我们在定义json的时候，可以先定义一个相应基类，包含code、msg等

2. 然后再定义一个DataResponseModel类，让其允许传入泛型，来动态决定data的类型

3. ```python
   class ResponseBaseModel(BaseModel):
       """
       响应模型
       """
   
       code: int = Field(default=HttpStatusConstant.SUCCESS, description='响应码')
       msg: str = Field(default='操作成功', description='响应信息')
       success: bool = Field(default=True, description='响应是否成功')
       time: datetime = Field(default_factory=datetime.now, description='响应时间')
       
   class DataResponseModel(ResponseBaseModel, Generic[T]):
       """
       数据响应模型
       """
   
       data: T = Field(description='响应数据')
   ```

4. 使用

   ```python
   @cache_controller.get(
       '/getNames',
       response_model=DataResponseModel[list[CacheInfoModel]],
   )
   async def get_monitor_cache_name(request: Request) -> Response:
       # 获取全量数据
       cache_name_list_result = await CacheService.get_cache_monitor_cache_name_services()
       logger.info('获取成功')
       return ResponseUtil.success(data=cache_name_list_result)
   ```

### 让字段在一维层面变化

1. 如原来的

   ```python
   {
     "file_url": "https://minio.example.com/bucket/file.pdf",
     "file_name": "speed_limit_cert.pdf",
     "file_size": 1024
   }
   ```

2. 变成

   ```python
   {
     "code": 200,
     "message": "上传成功",
     "timestamp": "2026-08-12T10:30:00Z",
     // UploadResponseModel 的所有字段被"平铺"到同一层级
     "file_url": "https://minio.example.com/bucket/file.pdf",
     "file_name": "speed_limit_cert.pdf",
     "file_size": 1024
   }
   ```

3. 完整代码

   ```python
   class DynamicResponseModel(ResponseBaseModel, Generic[T]):
       """
       动态响应模型
       """
   
       model_config = ConfigDict(alias_generator=to_camel)
   
       def __class_getitem__(cls, item: Any) -> Any | Self:
           """
           当使用 DynamicResponseModel[Item] 语法时，动态创建一个包含所有字段的新模型
           """
           # 检查是否已经为该类型创建了模型
           if not hasattr(cls, '_cached_models'):
               cls._cached_models = {}
   
           if item in cls._cached_models:
               return cls._cached_models[item]
   
           # 检查item是否为Pydantic模型
           if not hasattr(item, 'model_fields'):
               raise TypeError(f'{item} 不是一个Pydantic模型，请使用Pydantic模型作为泛型参数')
   
           # 获取ResponseBaseModel的字段
           base_fields = {}
           for field_name, field in cls.model_fields.items():
               base_fields[field_name] = (field.annotation, field)
   
           # 获取泛型类型的字段
           item_fields = {}
           for field_name, field in item.model_fields.items():
               item_fields[field_name] = (field.annotation, field)
   
           # 合并所有字段
           all_fields = {**base_fields, **item_fields}
   
           # 动态创建新模型
           new_model = create_model(
               f'DynamicResponseModel[{item.__name__}]', __base__=cls, __config__=cls.model_config, **all_fields
           )
   
           # 缓存模型
           cls._cached_models[item] = new_model
   
           return new_model
   ```

## 完整代码

```python
from datetime import datetime

from pydantic import BaseModel, ConfigDict, Field
from pydantic.alias_generators import to_camel
from pydantic_validation_decorator import NotBlank

class SessionsModel(BaseModel):
    """
    用户会话关联表对应pydantic模型
    """
    model_config = ConfigDict(alias_generator=to_camel, from_attributes=True)

    id: int | None = Field(default=None, description='主键ID')
    user_id: str | None = Field(default=None, description='用户ID')
    session_id: str | None = Field(default=None, description='会话ID')
    created_at: datetime | None = Field(default=None, description='创建时间')
    is_active: int | None = Field(default=None, description='是否仍在会话中: 1-是, 0-否')

    @NotBlank(field_name='user_id', message='用户ID不能为空')
    def get_user_id(self) -> str | None:
        return self.user_id

    @NotBlank(field_name='session_id', message='会话ID不能为空')
    def get_session_id(self) -> str | None:
        return self.session_id

    @NotBlank(field_name='created_at', message='创建时间不能为空')
    def get_created_at(self) -> datetime | None:
        return self.created_at


    def validate_fields(self) -> None:
        self.get_user_id()
        self.get_session_id()
        self.get_created_at()




class SessionsQueryModel(SessionsModel):
    """
    用户会话关联不分页查询模型
    """
    pass


class SessionsPageQueryModel(SessionsQueryModel):
    """
    用户会话关联分页查询模型
    """

    page_num: int = Field(default=1, description='当前页码')
    page_size: int = Field(default=10, description='每页记录数')


class DeleteSessionsModel(BaseModel):
    """
    删除用户会话关联模型
    """

    model_config = ConfigDict(alias_generator=to_camel)

    ids: str = Field(description='需要删除的主键ID')
```
