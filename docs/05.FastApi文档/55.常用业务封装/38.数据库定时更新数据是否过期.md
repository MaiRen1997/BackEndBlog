## 需求说明

1. 编写一个定时任务脚本，放在每天凌晨1点进行
2. 脚本逻辑是：
   1. 需要查询该数据库表中expired_time字段与当前年月日的差异，决定是否过期
   2. 如果过期了，需要将status置为1
   3. 在合并文档的时候，需要判断状态是否过期，如果过期了，需要返回：certification_no已过期，过期时间是：expired_time，
   4. 同时阻断文档的合并

## 实现

### 定义任务内容

```python
#certification_expiry_job.py

from config.database import AsyncSessionLocal
from module_certification.service.certification_expiry_service import CertificationExpiryService
from utils.log_util import logger


async def mark_expired_certifications() -> None:
    """每天凌晨 1 点将到期日期早于今天的证书状态置为 1。"""
    async with AsyncSessionLocal() as session:
        try:
            count = await CertificationExpiryService.mark_expired(session)
            await session.commit()
        except Exception:
            await session.rollback()
            logger.exception('证书过期状态更新失败')
            raise
    logger.info(f'证书过期状态更新完成，共更新 {count} 条记录')

```

### 增加时间判断脚本，用于校验日期是否过期

#### 代码说明

1. datetime.combine的用法：用于把一个**日期**和一个**时间**组合成完整的 `datetime` 对象
   1. `datetime.combine(date, time, tzinfo=time.tzinfo)`
      1. date	日期对象，提供年、月、日
      2. time	时间对象，提供时、分、秒、微秒
      3. tzinfo	可选的时区信息；省略时沿用 time 对象的时区
   2. time.min表示一天最早的时间，也就是 `00:00:00`
2. `_expired_before_today中的CertificateManange.expired_time，值从哪里来`
   1. 这里的 **`CertificateManange.expired_time` 不是通过参数传入的具体时间，而是 SQLAlchemy 模型中的数据库字段引用**
   2. 也就是说，它对应数据库中 `certificate_manange` 表的 `expired_time` 列
   3. 这里实际在做的是**构造数据库查询条件**
   4. 随后`_expired_before_today`被`mark_expired`调用
   5. `mark_expired` 在`get_scheduler.py`中被调用，帮传入了session

3. `mark_expired`方法中的`or_`的用法
   1. `or_` 是 SQLAlchemy 提供的函数，用来把多个条件按 **“或”** 连接起来：**任意一个条件成立，整体就成立**。

4. `CertificateManange.status.is_(None)`： 判断值是否是Null
5. `CertificateManange.status.in_(['0', '2'])`：判断值是否在区间内

```python
# certification_expiry_service.py

from datetime import date, datetime, time

from sqlalchemy import or_, select, update
from sqlalchemy.ext.asyncio import AsyncSession

from exceptions.exception import ServiceException
from module_certification.entity.do.certification_do import CertificateManange


class CertificationExpiryService:
    """按服务器本地日期判断过期，到期当天仍有效。"""

    @staticmethod
    def _expired_before_today(today: date):
        return CertificateManange.expired_time < datetime.combine(today, time.min)

    @classmethod
    async def mark_expired(cls, db: AsyncSession) -> int:
        result = await db.execute(
            update(CertificateManange)
            .where(
                cls._expired_before_today(date.today()),
                or_(CertificateManange.status.is_(None), CertificateManange.status != '1'),
            )
            .values(status='1')
        )
        return result.rowcount

    @classmethod
    async def validate_for_merge(
        cls, db: AsyncSession, certification_nos: list[str], file_urls: list[str]
    ) -> None:
        """同时检查证书编号和历史快照中的文件链接，阻断过期证书合并。"""
        if not certification_nos and not file_urls:
            return
        result = await db.execute(
            select(CertificateManange.certification_no, CertificateManange.expired_time)
            .where(
                or_(
                    CertificateManange.certification_no.in_(certification_nos),
                    CertificateManange.file_url.in_(file_urls),
                ),
                or_(CertificateManange.status == '1', cls._expired_before_today(date.today())),
            )
            .order_by(CertificateManange.id.desc())
        )
        expired = result.all()
        if expired:
            messages = [
                f'{cert_no}已过期，过期时间是：'
                f'{expired_time:%Y-%m-%d %H:%M:%S}'
                if expired_time is not None else f'{cert_no}已过期，过期时间是：未设置'
                for cert_no, expired_time in expired
            ]
            raise ServiceException(message='；'.join(messages))

```
