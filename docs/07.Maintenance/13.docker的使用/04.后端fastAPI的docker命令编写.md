## 命令

```bash
FROM python:3.10
WORKDIR /app

# 复制源代码
COPY . .

# 安装依赖
RUN sed '/^\.$/d' requirements.txt > /tmp/requirements.txt \
	&& pip install --no-cache-dir --no-build-isolation -r /tmp/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 暴露端口
EXPOSE 9099

# 启动命令
CMD ["python", "app.py", "--env=dockermy"]
```

## RUN

```bash
RUN sed '/^\.$/d' requirements.txt > /tmp/requirements.txt \
	&& pip install --no-cache-dir --no-build-isolation -r /tmp/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

1. sed '/^\.$/d' requirements.txt：删除requirements.txt中只包含单个点号.的行（可能是为了过滤掉某些特殊标记）

2. 过滤后保存到/tmp/requirements.txt

3. 使用清华镜像源安装依赖

4. --no-cache-dir：不缓存安装包，减小镜像体积

5. --no-build-isolation：禁用构建隔离，提高构建速度（适合有C扩展的包）
