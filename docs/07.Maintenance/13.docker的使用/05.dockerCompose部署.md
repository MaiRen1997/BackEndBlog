## 设置centOS镜像

```bash
vim /etc/docker/daemon.json
```

```bash
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://docker-0.unsee.tech",
    "https://docker.m.daocloud.io"
  ],
  "live-restore": true,
  "features": { "buildkit": true }
}
```

**重启服务**

```bash
sudo systemctl daemon-reload
sudo systemctl restart docker
```


## 代码拉取并更新

###  标准更新流程

```bash
# 拉取最新代码（如果有版本控制）
git pull

# 重新构建镜像（使用 --no-cache 避免缓存问题）
docker compose -f docker-compose.my.yml build --no-cache

# 停止旧容器并启动新容器
docker compose -f docker-compose.my.yml up -d
```

### 2. 一行命令完成（重建+重启）

```bash
docker compose -f docker-compose.my.yml up -d --build
```

- `--build`：启动前自动重新构建镜像

### 3. 强制重建所有服务

```bash
docker compose -f docker-compose.my.yml up -d --force-recreate --build
```

## 查看容器

### 查看容器状态

```bash
docker compose -f docker-compose.my.yml ps
```

## 查看日志

### 查看后端日志

```bash
docker compose -f docker-compose.my.yml logs -f rowen-backend-my
```

### 其他命令

```bash
# 查看所有服务日志
docker compose -f docker-compose.my.yml logs -f

# 查看后端日志
docker logs -f --tail 200 rowen-backend-my

# 查看前端 Nginx 日志
docker logs -f --tail 200 rowen-frontend

# 查看 Redis 日志
docker logs -f --tail 200 rowen-redis
```

### 查看日志文件

```bash
docker exec -it rowen-backend-my sh

ls -lh /app/logs
tail -f /app/logs/$(date +%Y/%m/%d)/info.log
tail -f /app/logs/$(date +%Y/%m/%d)/error.log
```

## 部署到服务器

1. 进入项目目录，找到docker-compose.my.yml
2. 运行命令 docker compose -f docker-compose.my.yml up -d进行部署

## 查看当前运行容器

上面使用了非标准的.my后缀，查看容器状态时，也要使用相同的命令

```bash
docker compose -f docker-compose.my.yml ps
```

### 如果容器已停止，加上 `-a` 查看所有

```bash
docker compose -f docker-compose.my.yml ps -a
```

## 停止容器

### 只停止容器

```bash
docker compose -f docker-compose.my.yml stop
```

### 停止并删除容器

```bash
docker compose -f docker-compose.my.yml down
```
