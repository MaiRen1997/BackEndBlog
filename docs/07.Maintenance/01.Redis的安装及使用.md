## CentOS安装redis

```bash
# 1. 安装 EPEL 仓库（如果还没安装）
sudo yum install epel-release -y

# 2. 安装 Redis
sudo yum install redis -y

# 3. 启动 Redis 服务
sudo systemctl start redis

# 4. 设置开机自启
sudo systemctl enable redis

# 5. 验证安装
redis-cli ping
# 如果返回 PONG，说明安装成功
```

## 基本配置

### 编辑redis.conf文件

```bash
# 编辑配置文件
sudo vi /etc/redis.conf
```

#### **建议修改以下配置**（生产环境必做）：

```bash
# 1. 设置密码（去掉 # 并修改）
requirepass your_strong_password

# 2. 允许远程访问（修改 bind）
bind 0.0.0.0

# 3. 设置最大内存（根据服务器配置调整）
maxmemory 1gb
maxmemory-policy allkeys-lru

# 4. 设置保护模式为 no（允许外部连接）
protected-mode no
```

### 重启redis

```bash
#1. 重启redis
sudo systemctl restart redis
#2. 再次确认监听地址
sudo netstat -tlnp | grep 6379
```

### 确认redis运行

```bash
sudo systemctl status redis
```

### 确认监听位置

```bash
sudo netstat -tlnp | grep 6379
```

```text
tcp        0      0 0.0.0.0:6379            0.0.0.0:*               LISTEN      1234/redis-server
```

如果显示 `127.0.0.1:6379`，说明 Redis 只监听本地，需要修改配置。

可以使用如下命令再改

```bash
# 1. 修改 bind 配置
sudo sed -i 's/bind 127.0.0.1/bind 0.0.0.0/' /etc/redis.conf

# 2. 修改保护模式（允许外部连接）
sudo sed -i 's/protected-mode yes/protected-mode no/' /etc/redis.conf
```



## 防火墙配置

```bash
# 开放 6379 端口
sudo firewall-cmd --permanent --add-port=6379/tcp
sudo firewall-cmd --reload

# 或者如果用的是 iptables
sudo iptables -A INPUT -p tcp --dport 6379 -j ACCEPT
```

## 测试连接

### 基于windows的powershell测试

```bash
powershell -c "Test-NetConnection 192.168.73.128 -Port 6379"
```

### 基于centOS测试

```bash
# 本地测试（有密码的情况）
redis-cli -a your_password

# 远程测试（从其他机器）
redis-cli -h your_server_ip -p 6379 -a your_password
```
