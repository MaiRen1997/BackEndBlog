## 准备工作

1. 在开始之前，你需要在服务器上确认两件事：
   1. 已安装 Docker 和 Docker Compose V2。你可以运行 docker compose version 来确认。
   2. 准备一个工作目录。建议把 Milvus 的数据放在一个单独的路径下，方便管理和备份。

## 下载配置文件

1. 登录到你的服务器，创建一个目录并下载官方的 Docker Compose 配置文件

   ```bash
   # 1. 创建 Milvus 工作目录（路径可按需更改）
   mkdir -p /data/containers/milvus && cd /data/containers/milvus
   
   # 2. 下载官方提供的 docker-compose.yml 文件
   wget https://github.com/milvus-io/milvus/releases/download/v3.0.1/milvus-standalone-docker-compose.yml -O docker-compose.yml
   ```

## 如果单独部署minio

### 修改docker-compose.yml

1. **注释掉或删除自带的 `minio` 服务**

   ```bash
   #  minio:
   #    container_name: milvus-minio
   #    image: minio/minio:RELEASE.2023-03-20T20-16-18Z
   #    environment:
   #      MINIO_ACCESS_KEY: minioadmin
   #      MINIO_SECRET_KEY: minioadmin
   #    ports:
   #      - "9001:9001"
   #      - "9000:9000"
   #    volumes:
   #      - ${DOCKER_VOLUME_DIRECTORY:-.}/volumes/minio:/minio_data
   #    command: minio server /minio_data --console-address ":9001"
   #    ...
   ```

2. **修改 `milvus-standalone` 服务的环境变量**

   1. 找到 `standalone` 服务，把 `MINIO_ADDRESS` 指向你现有的 MinIO，并补上 `MINIO_ACCESS_KEY_ID` 和 `MINIO_SECRET_ACCESS_KEY`：
   2. 注意：如果minio不是部署在docker里的，`IP地址要填写实际的IP地址，而不是localhost或者127.0.0.1`
   3. depends_on里，要删除掉minio

   ```bash
     standalone:
       container_name: milvus-standalone
       image: milvusdb/milvus:v2.4.x
       command: ["milvus", "run", "standalone"]
       environment:
         ETCD_ENDPOINTS: etcd:2379
         MINIO_ADDRESS: 192.168.1.100:9000        # 换成你现有 MinIO 的地址（不带 http://）
         MINIO_ACCESS_KEY_ID: your-access-key     # 换成你的 Access Key
         MINIO_SECRET_ACCESS_KEY: your-secret-key # 换成你的 Secret Key
         MINIO_BUCKET_NAME: milvus-bucket         # 换成你新建的 bucket 名
       ports:
         - "19530:19530"
         - "9091:9091"
       depends_on:
         - etcd
       # 注意：这里不再依赖 minio
   ```

### 修改存储路径权限

```bash
cd /data/containers/milvus
sudo chmod -R 777 volumes/milvus
```



## 启动服务

```bash
# 重新启动
sudo docker compose up -d

# 检查容器状态，确保 STATUS 列显示为 Up (healthy)
sudo docker compose ps
```

## 验证minio能连接上Minio

```bash
# 查看 Milvus 日志，确认没有 MinIO 连接错误
sudo docker logs milvus-standalone 2>&1 | grep -i minio
```

如果日志里没有报错（比如 `Access Denied`、`connection refused`），说明连接正常。你也可以去现有 MinIO 的控制台，看看 `milvus-bucket` 里是否开始出现 Milvus 写入的对象
