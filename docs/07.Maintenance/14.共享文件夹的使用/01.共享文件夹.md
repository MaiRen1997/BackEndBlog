## 前期准备

### 创建系统盘内文件夹

1. 创建影音文件夹

   ```bash
   sudo mkdir -p /mnt/media
   ```

### 修改外接盘挂载

#### 查看外界盘信息

1. 查看当前U盘信息

   ```bash
   lsblk -o NAME,SIZE,FSTYPE,LABEL,UUID,MOUNTPOINTS
   ```

2. 信息如下

   ```bash
   NAME         SIZE FSTYPE LABEL  UUID                                 MOUNTPOINTS
   sda         29.9G ntfs   新加卷 983805183804F6D2                     /media/wangbeijing/新加卷
   mmcblk0     29.7G                                                    
   ├─mmcblk0p1  512M vfat   bootfs F737-8E10                            /boot/firmware
   └─mmcblk0p2 29.2G ext4   rootfs d6ecfcd5-2703-41bf-9301-10c403b6fb0c /
   
   ```

#### 修改挂载路径

1. 可以看到，上述挂载路径是`/media/wangbeijing/新加卷`，卷名是`sda`

2. 先卸载

   ```bash
   umount "/media/wangbeijing/新加卷"
   ```

3. 需要将盘挂载到`/mnt/media`

   ```bash
   mount -t ntfs3 /dev/sda /mnt/media5
   ```

4. 在里面创建不同的文件目录

   ```bash
   sudo mkdir -p /mnt/media/Movies
   sudo mkdir -p /mnt/media/TV
   sudo mkdir -p /mnt/media/Music
   sudo mkdir -p /mnt/media/Photos
   ```

   

## 安装 NAS：Samba

### 安装：

```
sudo apt install samba -y
```

### 给 Samba 设置你的 NAS 用户密码：

```
sudo smbpasswd -a nas
```

输入一个密码。

### 设置用户文件夹权限

先让你的用户拥有媒体目录：

```bash
sudo chown -R nas:nas /mnt/media
```

然后：

```bash
sudo chmod -R 755 /mnt/media
```

### 配置 Samba

1. 打开文件

   ```bash
   sudo nano /etc/samba/smb.conf
   ```

2. 在文件最后加上

   ```bash
   [Media]
      path = /mnt/media
      browseable = yes
      read only = no
      writable = yes
      guest ok = no
      valid users = nas
      create mask = 0664
      directory mask = 0775
   ```

3. 测试文件

   ```bash
   testparm
   ```

4. 测试成功的结果

   ```bash
   root@raspberrypi:~# testparm
   Load smb config files from /etc/samba/smb.conf
   Loaded services file OK.
   Weak crypto is allowed by GnuTLS (e.g. NTLM as a compatibility fallback)
   
   Server role: ROLE_STANDALONE
   
   Press enter to see a dump of your service definitions
   ```

### 重启Samba服务

```bash
sudo systemctl restart smbd
sudo systemctl enable smbd
```

### 电脑访问共享文件夹

1. 文件资源管理器地址栏输入：

   ```
   \\192.168.1.13\Media
   ```

2. 输入用户名和密码

   ```bash
   用户名：nas
   密码：你刚刚设置的 Samba 密码
   ```

   

## 安装Jellyfin

1. 安装：

   ```bash
   sudo apt install curl -y
   ```

2. 然后：

   ```bash
   curl -s https://repo.jellyfin.org/install-debuntu.sh -O
   ```

3. 下载校验文件：

   ```bash
   curl -s https://repo.jellyfin.org/install-debuntu.sh.sha256sum -O
   ```

4. 验证：

   ```bash
   sha256sum -c install-debuntu.sh.sha256sum
   ```

5. 如果看到：

   ```bash
   OK
   ```

6. 再执行：

   ```bash
   sudo bash install-debuntu.sh
   ```

7. 安装完成：

   ```bash
   sudo systemctl enable --now jellyfin
   ```

8. 查看：

   ```bash
   systemctl status jellyfin
   ```

9. 应该是：

   ```bash
   active (running)
   ```

## 设置Jellyfin

### 访问页面

电脑浏览器访问：

```
http://192.168.1.13:8096
```

进入 Jellyfin 初始化页面。

### 设置语言和密码

1. 选择语言：

   ```
   中文
   ```

2. 然后创建管理员：

   ```
   用户名：admin
   密码：一个非常强的密码
   ```

3. **不要使用 NAS 的密码。**

------

### 添加电影库

1. 选择：

   ```
   Add Media Library
   ```

2. 类型：

   ```
   Movies
   ```

3. 名称：

   ```bash
   电影
   ```

4. 文件夹：

   ```
   /mnt/media/Movies
   ```

### 字幕设置

1. Jellyfin 本身可以读取视频旁边的字幕文件。

   1. 例如：

      ```
      Interstellar (2014).mkv
      Interstellar (2014).zh-CN.srt
      ```

   2. 或者：

      ```
      Interstellar (2014).chs.srt
      ```

   3. 常见的外挂字幕：

      ```
      .srt
      .ass
      .ssa
      ```

   4. 例如：

      ```
      Dune Part Two (2024).mkv
      Dune Part Two (2024).zh-Hans.srt
      ```

2. 我建议电影目录这样：

   ```bash
   Dune Part Two (2024)
   ├── Dune Part Two (2024).mkv
   └── Dune Part Two (2024).zh-Hans.srt
   ```

------

### 字幕会不会导致 Pi 4 转码？

1. 会，尤其是：

   ```
   ASS/SSA
   ↓
   字幕烧录
   ↓
   视频重新编码
   ```

2. 这会大幅增加 CPU/GPU 负担。所以家庭影院最理想的是：

   ```
   电影文件
   +
   电视支持的视频格式
   +
   电视支持的音频格式
   +
   外挂字幕
   ```

3. 让电视**直接播放原文件**。这叫：

   > Direct Play

   这是 Pi 4 家庭影院最理想的状态。

## 卸载U盘

### 卸载

1. 切换到根目录

   ```bash
   cd /
   ```

2. 卸载U盘

   ```bash
   umount /mnt/media5
   ```

3. 如果出现 `target is busy`

   1. 查看谁在使用

      ```bash
      lsof +D /mnt/media5
      ```

   2. 如果是`smbd`在占用，使用如下命令

      ```bash
      systemctl stop smbd
      ```

   3. 然后同步

      ```bash
      sync
      ```

   4. 然后再卸载

      ```bash
      umount /mnt/media5
      ```

4. 检查现在状态

   ```bash
   lsblk -o NAME,SIZE,FSTYPE,LABEL,UUID,MOUNTPOINTS
   ```

### 继续使用

```bash
systemctl start smbd
```
