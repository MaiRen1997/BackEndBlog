**2025 年的新版本 MinIO**，从这一代开始，**Console 已经基本不提供 Bucket 匿名访问策略（Anonymous Policy）的修改入口**，官方推荐全部使用 **mc（MinIO Client）** 来管理

# 第二步：安装 mc（MinIO Client）

如果没有安装：

```
wget https://dl.min.io/client/mc/release/linux-amd64/mc

chmod +x mc

mv mc /usr/local/bin/
```

检查：

```
mc --version
```

------

# 第三步：连接你的 MinIO

假设：

- 用户：admin
- 密码：12345678
- 地址：`http://10.13.0.171:9000`

执行：

```
mc alias set myminio http://10.13.0.171:9000 admin 12345678
```

成功会显示：

```
Added `myminio` successfully.
```

------

# 第四步：把 Bucket 设置为公开下载

执行：

```
mc anonymous set download myminio/certification
```

然后查看：

```
mc anonymous get myminio/certification
```

应该看到类似：

```
Access permission for `myminio/certification` is `download`
```

这时浏览器访问：

```
http://10.13.0.171:9000/certification/test1.txt
```

就不会再出现 `AccessDenied`。
