## 切换步骤

### 先停止 MinIO 服务（保证数据一致性）

```bash
systemctl stop minio
```

### 查看盘状态并挂载

#### 查看盘状态

1. 命令

   ```bash
   lsblk -f
   ```

2. 结果

   ```bash
   [root@localhost admin]# lsblk -f
   NAME            FSTYPE      LABEL UUID                                   MOUNTPOINT
   sda                                                                      
   ├─sda1          xfs               97c63402-f95f-418c-8e41-a21fb928c996   /boot
   └─sda2          LVM2_member       CurGe9-Fe7f-W7yr-HBLa-pWwX-47U7-2uyqft 
     ├─centos-root xfs               1aeae17f-054d-4909-88a1-06b44325ca4f   /
     ├─centos-swap swap              e069d193-f9c0-4593-aad9-445712aabdc0   [SWAP]
     └─centos-home xfs               d0414901-7493-4117-a210-18183019cc9d   /home
   sdb             ext4        data  8be70b41-4889-43a4-b7b8-88a4ddf96de2   
   sr0  
   ```

#### 挂载盘

1. 创建挂载节点

   ```bash
   mkdir -p /run/media/admin/data
   chmod 755 /run/media/admin
   chmod 755 /run/media/admin/data
   ```

2. 使用fstab挂载

   ```bash
   # 2. 确认 fstab 有那一行（没有就加上）
   grep "8be70b41-4889-43a4-b7b8-88a4ddf96de2" /etc/fstab
   # 如果没有输出，就加上：
   # echo 'UUID=8be70b41-4889-43a4-b7b8-88a4ddf96de2  /run/media/admin/data  ext4  defaults,nofail  0  2' >> /etc/fstab
   
   # 3. 挂载
   mkdir -p /mnt/storage
   chmod 755 /mnt/storage
   chmod 755 /mnt/storage
   mount /dev/sdb /mnt/storage
   
   # 4. 确认
   mount | grep /mnt/storage
   df -h /mnt/storage
   ```

### 用 rsync 复制数据（推荐，可续传、保留权限）

```bash
# 注意结尾斜杠：/data/minio-data/ 会把"里面的内容"复制到目标
rsync -aAXHv --progress /data/minio-data/ /mnt/storage/
```

参数说明：

- `-a` 归档模式（递归、保留权限/时间/软链）
- `-A` 保留 ACL
- `-X` 保留扩展属性（**MinIO 依赖 xattr 存储元数据，这一项很重要**）
- `-H` 保留硬链接
- `-v --progress` 显示进度

如果数据量大、想加校验：

```bash
rsync -aAXHv --progress --checksum /data/minio-data/ /mnt/storage/
```

### 3. 校验（可选但强烈建议）

```bash
# 对比文件数量
find /data/minio-data -type f | wc -l
find /mnt/storage     -type f | wc -l

# 或用 rsync 空跑对比差异
rsync -aAXHn --delete --itemize-changes /data/minio-data/ /mnt/storage/
# 没有输出 = 完全一致
```

### 4. 修改配置

```bash
vim /etc/default/minio
# 改成：
MINIO_VOLUMES="/mnt/storage"
```

> ⚠️ 注意：这里要看你原来 MinIO 是"单盘模式"还是"多盘模式"。
>
> - 如果是 `MINIO_VOLUMES="/data/minio-data"`，那 `/mnt/storage` 就是新的数据根目录。
> - 复制时是把 `minio-data` **里面的内容**（`.minio.sys`、各 bucket 目录）放到 `/mnt/storage/` 下，而不是把 `minio-data` 整个目录塞进去。

### 5. 设置权限

```bash
chown -R minio:minio /mnt/storage
```

### 6. 启动并验证

```bash
systemctl start minio
systemctl status minio
```

浏览器打开 Console，确认 bucket 和对象都在。

### 7. 确认无误后再删除旧数据

**不要急着删**，先观察一两天：

```bash
# 确认没问题后
rm -rf /data/minio-data
```
