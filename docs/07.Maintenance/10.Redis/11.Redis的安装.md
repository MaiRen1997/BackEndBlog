## CentOS安装redis

```bash
# 1. 安装 EPEL 仓库（如果还没安装）
sudo yum install epel-release -y

# 2. 安装 Redis
sudo yum install redis -y

# 3. 启动 Redis 服务
sudo systemctl start redis

# 4. 设置开机自启
sudo systemctl enable redis

# 5. 验证安装
redis-cli ping
# 如果返回 PONG，说明安装成功
```

## 安装Redis6

### 安装依赖及下载源码

```bash
# 安装编译工具 (gcc) 和 make
sudo yum install -y gcc make

# 下载 Redis 6.2.6 源码包 (这是一个广泛使用的稳定版)
wget http://download.redis.io/releases/redis-6.2.6.tar.gz

# 解压源码包
tar xzf redis-6.2.6.tar.gz

# 进入解压后的目录
cd redis-6.2.6
```

### 编译与安装

```bash
# 开始编译 (这一步会花费几分钟)
make

# 将编译好的程序安装到系统路径 (/usr/local/bin)
sudo make install
```

**如果 `make` 命令失败，并且错误信息与 `gcc` 版本有关**，说明需要升级 gcc。可以按顺序执行以下命令进行升级：

bash

```
# 1. 安装SCL软件集
sudo yum install -y centos-release-scl
# 2. 安装新版gcc (devtoolset-9)
sudo yum install -y devtoolset-9-gcc devtoolset-9-gcc-c++
# 3. 启用新版gcc (临时生效，仅当前会话)
scl enable devtoolset-9 bash
# 4. 重新执行编译和安装
make distclean && make
sudo make install
```

如果想永久启用新版gcc，可以执行 `echo "source /opt/rh/devtoolset-9/enable" >> ~/.bashrc`

## 基本配置

### 编辑redis.conf文件

```bash
# 创建存放配置文件的目录
sudo mkdir /etc/redis

# 将源码目录中的默认配置文件复制过来
sudo cp redis.conf /etc/redis/6379.conf

# 编辑配置文件
sudo vi /etc/redis/6379.conf
```

#### **建议修改以下配置**（生产环境必做）：

```bash
# 1. 设置密码（去掉 # 并修改）
requirepass your_strong_password

# 2. 允许远程访问（修改 bind）
bind 0.0.0.0

# 3. 设置最大内存（根据服务器配置调整）
maxmemory 1gb
maxmemory-policy allkeys-lru

# 4. 设置保护模式为 no（允许外部连接）
protected-mode no

# 5.后台运行，不占用终端
daemonize yes
```

### 启动redis

```bash
# 使用你刚配置好的文件来启动 redis-server
redis-server /etc/redis/6379.conf
```

### 查看是否运行在终端

```bash
ps -ef | grep redis
```

## 设置开机自启

### **设置开机自启**：可以创建一个 systemd 服务，让 Redis 在服务器重启后能自动启动，无需手动操作。

1. **创建服务文件**：`sudo vi /etc/systemd/system/redis.service`

2. **写入以下内容**：

   ```bash
   [Unit]
   Description=Redis Server
   After=network.target
   
   [Service]
   Type=forking
   ExecStart=/usr/local/bin/redis-server /etc/redis/6379.conf
   ExecStop=/usr/local/bin/redis-cli -a '你的密码' shutdown
   Restart=always
   
   [Install]
   WantedBy=multi-user.target
   ```

3. **启用服务**：

   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable redis
   sudo systemctl start redis
   sudo systemctl status redis
   ```

### 重启redis

```bash
#1. 重启redis
sudo systemctl restart redis
#2. 再次确认监听地址
sudo netstat -tlnp | grep 6379
```

### 确认redis运行

```bash
sudo systemctl status redis
```

### 确认监听位置

```bash
sudo netstat -tlnp | grep 6379
```

```text
tcp        0      0 0.0.0.0:6379            0.0.0.0:*               LISTEN      1234/redis-server
```

如果显示 `127.0.0.1:6379`，说明 Redis 只监听本地，需要修改配置。

可以使用如下命令再改

```bash
# 1. 修改 bind 配置
sudo sed -i 's/bind 127.0.0.1/bind 0.0.0.0/' /etc/redis.conf

# 2. 修改保护模式（允许外部连接）
sudo sed -i 's/protected-mode yes/protected-mode no/' /etc/redis.conf
```



## 防火墙配置

```bash
# 开放 6379 端口
sudo firewall-cmd --permanent --add-port=6379/tcp
sudo firewall-cmd --reload

# 或者如果用的是 iptables
sudo iptables -A INPUT -p tcp --dport 6379 -j ACCEPT
```

## 测试连接

```bash

redis-cli -h your_server_ip -p 6379 -a your_password
```
