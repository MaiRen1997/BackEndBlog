## Redis 有什么作用？

1. **缓存（最核心用途）**
   - 把数据库热点数据放到 Redis，减轻 MySQL 压力，提升响应速度。
2. **高性能读写**
   - 内存操作，微秒级响应，适合高并发场景。
3. **分布式共享数据**
   - 多台服务器共享同一个 Redis，如分布式 Session、分布式锁。
4. **消息队列 / 发布订阅**
   - List、Stream、Pub/Sub 可实现简单的消息队列。
5. **计数器 / 排行榜**
   - 原子自增（INCR）、ZSet 实现排行榜。
6. **限流 / 去重**
   - 利用过期时间、Set 做接口限流、UV 统计。

## Redis常见语法

### 通用命令

```bash
SET key value          # 设置
GET key                # 获取
DEL key                # 删除
EXISTS key             # 是否存在
EXPIRE key 60          # 60秒后过期
TTL key                # 查看剩余过期时间
KEYS pattern           # 查找 key（生产慎用）
TYPE key               # 查看类型
```

###  String（字符串）

```bash
SET name "张三"
GET name
INCR count             # 自增1
INCRBY count 10        # 自增10
SETEX code 300 "8888"  # 设置并带过期时间
MSET k1 v1 k2 v2       # 批量设置
MGET k1 k2             # 批量获取
```

### List（列表，有序可重复）

```bash
LPUSH list a b c       # 左边插入
RPUSH list x y z       # 右边插入
LRANGE list 0 -1       # 查看全部
LPOP list              # 左边弹出
RPOP list              # 右边弹出
LLEN list              # 长度
```

### Hash（哈希，类似对象）

```bash
HSET user:1 name "Tom" age 18
HGET user:1 name
HGETALL user:1
HDEL user:1 age
HINCRBY user:1 age 1
```

### Set（集合，无序不重复）

```bash
SADD tags java redis mysql
SMEMBERS tags
SISMEMBER tags java    # 是否存在
SCARD tags             # 元素个数
SINTER set1 set2       # 交集
SUNION set1 set2       # 并集
```

### ZSet（有序集合，带分数）

```bash
ZADD rank 100 Tom 90 Jerry 80 Spike
ZRANGE rank 0 -1 WITHSCORES        # 升序
ZREVRANGE rank 0 -1 WITHSCORES     # 降序（排行榜）
ZINCRBY rank 5 Tom                 # 加分
ZSCORE rank Tom
```

### 发布订阅

```bash
SUBSCRIBE channel      # 订阅
PUBLISH channel "msg"  # 发布
```

### 事务

```bash
MULTI
SET a 1
INCR a
EXEC
```

### 其他常用

```
FLUSHDB       # 清空当前库（慎用！）
FLUSHALL      # 清空所有库（慎用！）
INFO          # 查看状态
DBSIZE        # key 数量
```
